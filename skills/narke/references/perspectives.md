# 2つの視点・わかったふりのサイン・深掘りの問い

## 目次

1. フレッシュアイの問い
2. 哲学者の問い
3. 概念・資格の勉強で使う問い
4. わかったふりのサイン
5. 深掘りの問い
6. 誤った答えへの深掘り

## 1. フレッシュアイの問い

資料の読み手が共有していない前提を確かめる。読み手が迷う箇所を探す。

| 種類 | 問いの例 | 何を確かめるか |
|---|---|---|
| 要旨 | 「このページで、相手に何をしてほしいのですか。1〜2文で答えてください」 | 資料の目的を自分で持っているか |
| 説明不足 | 「〇〇を、この資料を見ていない人に説明してください」 | 用語を自分の言葉に置き換えられるか |
| 迷う箇所 | 「この図の矢印は何を意味しますか」「縦軸は何ですか」 | 図表を読めているか |
| 具体 | 「具体的に、誰のどの業務が変わりますか」 | 抽象論を現実に落とせるか |
| 実行 | 「最初の1か月で、誰が何をしますか。費用はいくらですか」 | 実行の姿を描けているか |
| 反論 | 「『うちには当てはまらない』と言われたら、どう答えますか」 | 想定外の問いに答えられるか |

## 2. 哲学者の問い

主張の土台を確かめる。

| 種類 | 問いの例 | 何を確かめるか |
|---|---|---|
| 定義 | 「ここで言う『最適化』は、何が何に対して良くなることですか」 | 中心の語の意味を決めているか |
| 区別 | 「案A と案B は、何を基準に分けていますか」 | 似たものを区別できるか |
| 隠れた前提 | 「この結論が成り立つには、何が真でなければなりませんか」 | 書かれていない条件に気づいているか |
| 根拠と証拠 | 「この数字は、何を何で割ったものですか。いつの、どこのデータですか」 | 数字と事実の出所を知っているか |
| 推論 | 「A だから B と言える理由は何ですか。B の原因が A ではない可能性は？」 | 論理の飛躍に気づいているか |
| 反例 | 「この主張が当てはまらない例を1つ挙げてください」 | 主張の限界を知っているか |
| 適用範囲 | 「この結論は、どんな条件のときに成り立たなくなりますか」 | 結論の及ぶ範囲を知っているか |

## 3. 概念・資格の勉強で使う問い

| 種類 | 問いの例 |
|---|---|
| 定義 | 「〇〇とは何ですか。教科書の言葉を使わずに」 |
| 区別 | 「〇〇と△△の違いは何ですか。どちらか一方にだけ当てはまる例を1つずつ」 |
| 理由 | 「なぜこの制度（仕組み）があるのですか。無かったら何が困りますか」 |
| 適用 | 「次の事例は〇〇に当たりますか。理由は？」（事例はレビューする側が作る。架空の事例だと書く） |
| 誤解 | 「『〇〇は常に△△である』は正しいですか」（よくある誤解を正誤の問いにする） |
| つながり | 「〇〇は、前に出てきた△△とどう関係しますか」 |
| 例外 | 「この原則が当てはまらない場合はありますか」 |

勉強では、レビューする側の知識の誤りが、そのまま利用者に入る危険がある。
試験範囲・法令・数値は、利用者の教材か公式の出典で確かめる。確かめていなければ「未確認:」と書く。

## 4. わかったふりのサイン

次のサインが1つ出たら、わかったふりを疑う。2つ以上出たら、わかったふりと判定し、評価を 0（なぞり・断定）にする。
対話の途中では、判定を伝えない。代わりに、サインを避けた言い直しを求める深掘りの問いを返す。
判定とサインの具体的な指摘（「いまの答えは、資料 p.3 の文とほぼ同じです」）は、理解度レポートの講評に書く。

| サイン | 例 |
|---|---|
| 資料の言い回しの繰り返し | 資料の文をほぼそのまま返す。語順だけを変える |
| 定義の無い専門用語で説明する | 「DX による業務の最適化です」— 用語を別の用語で説明している |
| 曖昧な語で逃げる | 「一般的に」「〜的に」「いろいろな」「など」「ある程度」「最適な形で」 |
| 主語・対象が無い | 「効率化されます」— 誰の何が、が無い |
| 長いが中身が無い | 3文以上あるのに、問いに答えている文が無い |
| 問いをすり替える | 「なぜ」に「何を」で答える。数字の出所を問われて、数字の意味を答える |
| 根拠が「AI がそう書いた」「資料にある」 | 自分で確かめていない |
| 自信の無い肯定 | 「たぶん〜だと思います」のあとに根拠が無い |

サインは判定の材料であって、責める材料ではない。
深掘りの問いは「『最適』『DX』を使わずに、資料を見ていない人に向けて言い換えると、どうなりますか」のように書く。

## 5. 深掘りの問い

| 欠けているもの | 深掘りの問い |
|---|---|
| 根拠 | 「なぜそう言えますか」「どこで確かめましたか」 |
| 範囲 | 「それはいつも成り立ちますか」 |
| 具体 | 「例を1つ挙げてください」 |
| 自分の言葉 | 「中学生に説明するなら？」「ひと言で言うと？」 |
| 比較 | 「〇〇と比べると？」 |
| 結果 | 「それで、相手にとって何が変わりますか」 |

## 6. 誤った答えへの深掘り

誤った答えには、正解を示さない。利用者が自分で誤りに気づける問いを返す。
『メノン』で、ソクラテスは少年に「では4×4はいくつか」と問い、少年が自分の答えの誤りに気づくようにした。Narke も同じ形をとる。

| 誤りの種類 | 自分で確かめられる問い |
|---|---|
| 計算の誤り | 「p.3 の表の数字から、年間の時間を計算するといくつになりますか」 |
| 資料の読み違い | 「p.4 の3番目の項目には、何と書いてありますか」 |
| 食い違いの見落とし | 「p.4 の対象と p.5 の対象を並べると、どうなりますか」 |
| 概念の取り違え | 「その説明だと、〇〇の場合はどちらに当たりますか」（反例になる事例を示す） |

誘導しすぎない。答えをほぼ含む問い（「これは〜ではないですか」）を重ねると、利用者は考えずに「はい」と答えるだけになる。
『メノン』の後半の問いには、この誘導が強いという批判がある。Narke は、確かめる材料（ページ・計算・事例）を示すところまでにとどめる。
